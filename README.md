## What it does

**Share by genre.** Your library is organised into genres your admin sets up (Afro House, Techno, Drum & Bass, whatever your crew plays). Add a track and everyone sees it in the right folder.

**You choose what lands on your disk.** New tracks from friends wait in *New music*. Download the ones you want, skip the rest, or set a genre to download automatically.

**Play before you download.** Preview any track straight from whoever has it, then keep it if it's a keeper.

**Always available.** A track downloads from anyone online who has it, not just the person who added it. Big files come in from several friends at once.

**Your files stay where they are.** Nadirect indexes your music in place and never copies or moves it. Downloads go into plain genre folders you can point Rekordbox, Serato or Traktor at.

**Easy on your connection.** You set how much upload to share (2 MB/s by default), pause sharing any time, or share only during certain hours.

## Private by design

- **Invite only.** A friend needs your invite code *and* the admin's approval to get in.
- **No cloud.** Music goes directly between members' computers, end-to-end encrypted. There's no Nadirect server, no account and no tracking.
- **Every file is checked.** Each piece of a track is verified against the fingerprint of the original, so a corrupted or altered file is refused. Only real audio files are accepted.
- **Signed updates.** Every release is signed. Nadirect refuses an update that doesn't carry the right signature and asks you before installing.

## Install

Get the latest version from **[Releases](https://github.com/itay5731/Nadirect-releases/releases/latest)**.

**Windows:** download `Nadirect-Setup-x.y.z.exe` and run it. When Windows asks whether Nadirect can use the network, choose **Allow**.

**macOS** (Apple Silicon and Intel): download `Nadirect-x.y.z-mac.dmg`, open it and drag Nadirect into Applications. The app isn't signed with an Apple developer account yet, so the first time:

1. Right-click Nadirect in Applications and choose **Open**, then **Open** again.
2. If macOS says the app is damaged, run this in Terminal:
   ```
   xattr -cr /Applications/Nadirect.app
   ```

When macOS asks about incoming connections, choose **Allow**.

**Joining a library:** open Nadirect, paste the invite code your admin sent you, and wait for them to approve you.

## Updates

Nadirect checks this page for new versions. When one is available it downloads it in the background, checks the signature, and asks before installing. On a Mac it opens the new version for you to drag into Applications.
